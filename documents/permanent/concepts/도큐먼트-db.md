# 도큐먼트 데이터베이스(Document Database)

## 정의

컬렉션(폴더) 안에 도큐먼트(파일)를 두고 각 도큐먼트에 JSON 형태로 데이터를 저장하는 NoSQL DB; 스키마를 미리 정의하지 않고 정규화를 하지 않아 유연한 구조와 단순한 입출력 문법을 갖추며, 수평 분산 처리를 염두에 두고 설계된다.

## 맥락

도큐먼트 DB는 정확도보다 **대량 입출력**이 중요한 서비스에 적합하다. 스키마가 없으므로 필드를 자유롭게 추가해도 에러가 발생하지 않으며, 정규화를 하지 않아 데이터 중복을 허용하는 대신 입출력 쿼리가 단순해진다. 분산 환경에서 수평 확장(스케일아웃)이 쉬운 반면, DB 인스턴스 간 데이터 일관성이 떨어질 수 있는 것이 트레이드오프다.

관계형 DB와의 핵심 차이: 관계형 DB가 트랜잭션·정규화로 데이터 정확도를 우선하는 데 반해, 도큐먼트 DB는 대량 입출력과 유연한 구조를 우선한다.

대표 DBMS: MongoDB, CouchDB, Firestore.
