# 프로세스(Process)

## 정의

운영체제로부터 코드(Code)·데이터(Data)·힙(Heap)·스택(Stack) 4개 메모리 영역을 독립적으로 할당받아 실행되는 작업의 단위; 각 프로세스는 독립적 주소 공간을 가져 다른 프로세스와 격리된다.

## 맥락

프로세스는 자원 할당의 기본 단위다. 독립적 주소 공간을 소유하므로 하나의 프로세스가 종료·충돌해도 다른 프로세스에 영향을 주지 않는다(격리성). 프로세스 간 데이터 공유는 IPC(Inter-Process Communication)와 같은 별도 메커니즘을 통해서만 가능하다.

[[컨텍스트-스위칭]] 시 프로세스 전환은 주소 공간 전체를 교체해야 하므로 [[쓰레드]] 전환에 비해 비용이 크다.
